Batch3: 中京芝2000 / 京都芝2000 / 京都芝2200
JRA公式の確認済みレースサンプルをまとめたもの。

重要:
- course-time-baselines-batch3-provisional.csv は確認済みサンプルからの暫定候補。
- 過去5年の「全レース完全網羅」ではないため sampleCount<15 は低信頼のまま。
- 中京2000は2021-2025金鯱賞5件。
- 京都2000は2023-2025秋華賞 + 2024-2025アンドロメダSの5件。
- 京都2200は2023-2025エリザベス女王杯 + 2024-2025京都記念 + 2024宝塚記念の6件。
- 2023京都記念は阪神開催なので京都2200サンプルから除外。

final3Fについて:
- 添付の final3F candidate は「各レース勝ち馬の推定上がり3F」の中央値。
- 現行 courseFinal3FBaseline が「レース全体/各馬の典型上がり」を意味するなら定義が一致しない可能性がある。
- よって DO NOT AUTOIMPORT。Claude側で現行定義を確認し、定義不一致なら報告だけすること。

狙い:
1) まず raceTimeScore の70 fallbackを、低信頼でも実データ候補に置換できるか検証。
2) final3F absolute部は定義確認後にのみ投入。
3) 数式・重み・MIN_RELIABLE_SAMPLE_COUNTは変更しない。
