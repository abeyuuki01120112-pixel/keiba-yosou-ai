## STEP8: scale順位の再確認（保守性・依存性・方向別バランスを含めて）

| 観点 | 評価 |
|---|---|
| 過補正（±10%・±5%） | scale=2.5〜4.0いずれも発生せず（差別化材料にならない） |
| 安定性（LOHO） | いずれのscaleでも順位安定（差別化材料にならない） |
| 能力9割思想 | いずれのscaleでも整合（差別化材料にならない） |
| 特定馬依存 | 依存はscale選択と無関係にほぼ解消済み（差別化材料にならない） |
| 方向別バランス | positive側の分散はscaleが大きいほど拡大（＝差を残す）、negative側はscaleに鈍感 |
| 解釈可能性 | いずれのscaleも同等 |

**上記6観点のうち5つはscale候補を差別化しない。** 唯一意味のある違いは
「positive側でどれだけ差を残すか」であり、scaleが大きいほど強い正のdelta
同士の違いを潰さずに保持できる（例: igacchiのaggregatedDelta=8.95と
2021103272の9.90は、scale=2.5ではどちらもほぼ105.0に張り付くが、scale=4.0
では103.9と104.2程度まで差が残る）。**これは「保守的だから4.0が良い」という
単純な話ではなく、「大きなpositive deltaの間の相対的な違いを保持したい
なら、scaleは小さすぎない方がよい」という具体的な実データ根拠である。**

**9項目は達成、条件9のみ未達。** 条件9について: STEP8で示した通り、
positive側の分散保持という観点でscaleを大きくする方向の実データ根拠は
提示できたが、これは「2.5より3.5・4.0の方が良い」という**範囲の絞り込み**
であって、「3.0・3.5・4.0のうちこの1点」という**単一値の確定根拠**には
なっていない。参考として、全deltaのIQR（四分位範囲）=P75(4.25)−P25(-0.20)
=4.45であり、一般的な帯域幅選択の直感（scaleをデータの典型的なばらつき
スケールに合わせる）に従うなら、scale=3.0よりもscale=4.0の方がこの
IQRに近い。**この観点でも、3.0を単独で選ぶ根拠は無く、むしろ3.5〜4.0を
支持する。**

**A判定の10条件は「すべて満たすこと」が前提であり、条件9が未達である以上、
無理にA判定にはしない。**

## STEP11: scale=3.0 / 3.5 / 4.0 個別判定

| scale | 条件1〜8・10（安全性・安定性・方向バランス） | 条件9（固有の説明可能性） | 判定 |
|---|---|---|---|
| **3.0** | 達成 | **最弱**——IQRヒューリスティック(4.45)からも、STEP8のpositive側分散保持の観点からも、3.0を2.5や3.5より積極的に選ぶ根拠が無い | **B** |
| **3.5** | 達成 | **中程度**——IQR(4.45)に3.0より近く、positive側分散保持も3.0よりやや優れる（0.71 vs 0.50）。ただし3.5固有の優位性（4.0との違い）を示す根拠は弱い | **B**（3候補中もっとも支持材料が多い） |
| **4.0** | 達成 | **中程度**——IQR(4.45)に最も近く、小delta過大評価が最も少ない（STEP4感度分析、CHECKPOINT11.6参照：delta=0.5で+0.6pt、3候補中最小）。ただし「4.0固有」の説明であって「4.0ではなく3.8や4.2ではないか」への回答にはならない | **B**（4.0固有というより「保守的な範囲の代表値」） |

**「なぜ3.0なのか／なぜ3.5なのか／なぜ4.0ではないのか」の比較**:
- 3.0を選ぶ理由: 積極的な根拠は無い。中央的な値というだけでは
  CHECKPOINT11.6以来禁止されている理由付けになってしまう。
- 3.5を選ぶ理由: IQRとpositive分散保持のバランスで3.0よりやや優位。
  ただし4.0との違いを明確に区別する根拠は無い。
- 4.0を選ばない理由: 明確な根拠は無い——むしろIQRヒューリスティックや
  小delta過大評価の抑制という点では4.0が3候補中もっとも支持材料が多い。
  「4.0ではなく3.0」を選ぶ理由の方が、むしろ説明に窮する。

**3候補すべてB判定。強いて優先順位をつけるなら、実データが示す傾向は
3.0 < 3.5 < 4.0の順で支持材料が増える。**
