**本ドキュメントはdocsの新規作成のみであり、既存実装（Base Ability V1・
Suitability V1・Stage A・Stage B・STEP6確率エンジン等）は一切変更していない。**
新機能の実装にも今回は着手しない。

## 4. 良かった点

1. **上位3頭の完全抽出**（3-3節）。オッズや市場情報を一切使わずに、11頭中3頭に
   母集団を正しく絞り込めた。これはAI最終順位の中で最も評価すべき成果である。
2. **最下位の的中**（ステレンボッシュ、予測11位→実着11位、差分0）。CHECKPOINT14D.2で
   「データ不足ではなく、証拠が十分な上での正当な低評価」と監査済みだった馬が、
   実際に最下位でレースを終えた。
3. **2位の完全一致**（ロデオドライブ、差分0）。
4. **Track Bias/Weather Diagnosticの方向性が結果的に妥当だった**。予測時点で
   「降雨リスクが高い」「馬場は良から稍重方向へ悪化しつつある」とDiagnostic表示
   していた内容は、実際に「天候:雨、馬場:稍重」という結果と整合する。ただし
   これはDiagnostic表示のみでScoreには反映していなかった点に注意（7節）。
5. **evaluationConfidence=unknownという申告自体の妥当性**。1〜3着が同タイム・
   アタマ差2つという大接戦になった事実は、「現時点の情報だけでは確信度を
   高く出せない」というAIの自己申告と方向性が一致している。

## 5. ズレた点

1. **上位3頭内部の序列が完全に逆転**した（3-3節）。AIが最も能力が高いと
   評価したダノンシーマ（80点）が3着、逆に3番手評価だったゾロアストロ（74点）が
   1着。ただし1〜3着の着差はいずれもアタマ差であり、統計的にはほぼ実力伯仲の
   結果を「僅差で割った」ようなレースだったとも解釈できる。
2. **バレエマスターの大幅な下振れ**（予測4位→実着10位、差分−6、今回最大のズレ）。
   Stage Aでは11頭中唯一、新潟芝2000mでの実走実績（2026新潟大賞典2着）を
   持つ馬としてdistance/course/gateの3component全てがプラス評価され、
   baseAbility以上に押し上げられていた（CHECKPOINT14D.2参照）。この「新潟実績
   による適性評価」が今回は結果に結びつかなかった。
3. **ジュンブロッサムも同様に下振れ**（予測5位→実着9位、差分−4）。同じく新潟
   での実績（2026関越ステークス、course component評価）を根拠にプラス評価
   されていたが、結果は伴わなかった。
4. **新潟実績ベースのcourse適性評価は、今回n=3（ゾロアストロ・バレエマスター・
   ジュンブロッサム）で1勝2敗**。ゾロアストロは的中（1着）、バレエマスター・
   ジュンブロッサムは大きく外れた。サンプル数が3では方向性の是非を判断できず、
   「新潟実績評価が機能した／しなかった」と結論づけることはできない。
5. **サヴォーナ・アーバンシック・ドゥレッツァ・チェルヴィニアが揃って予測より
   上振れ**（差分+2〜+4）。これらは共通してbaseAbility中位〜下位でSuitability
   がほぼ中立（新潟実績なし、distanceのみ評価）の馬であり、Stage A/Bのどの
   componentにも大きな加点材料が無かった馬たちである。中位集団の中での
   相対順位づけが、今回の実際の決着とはあまり相関しなかったことを示唆する。
6. **Race Pace Prediction（Diagnostic）の想定が"average"、実際は"S"（スロー）**。
   `racePacePrediction.ts`（CHECKPOINT14C、Diagnostic専用）およびStage Bで
   実際にScoreへ接続されているlegacy`predictedPace.ts`のいずれも"average"と
   判定していたが、実際の公式ペース区分は"S"だった。この診断のズレはStage B
   Scoreそのものには影響していない（"average"のPACE_LEVEL_SCOREは0で、
   脚質による有利不利がそもそも生まれない設計のため）が、ペース想定ロジック
   自体の精度としては外れたことを記録しておく。

## 6. PASS判断は妥当だったか

**予測精度の評価と投資判断の評価は分けて記録する。**

### 6-1. 予測精度としての評価

上位3頭の完全抽出（3-3節）という成果があった一方、期待値ランキング上位
（value pick）5頭の実際の成績は割れた:

| Value Pick | 実着順 |
|---|---|
| ボーンディスウェイ | 7着 |
| ジュンブロッサム | 9着 |
| バレエマスター | 10着 |
| サヴォーナ | 4着 |
| アーバンシック | 5着 |

5頭中2頭（サヴォーナ・アーバンシック）のみが馬券圏（5着以内）に絡み、
残り3頭（ボーンディスウェイ・ジュンブロッサム・バレエマスター）は下位に
沈んだ。つまり**「市場オッズに対してAI評価が相対的に高かった馬」が
必ずしも好走したわけではない**——これは今回のPASS判断（investment判断）とは
別に、期待値算出そのものの予測精度に課題があったことを示す。

### 6-2. 投資判断（BET/PASS）としての評価

上記6-1の通り、value pick 5頭中3頭が着外相当（7・9・10着）に沈んだ結果を見ると、
**もしこれらへ単勝で賭けていた場合、収支は悪化していた可能性が高い。**
その意味で、「evaluationConfidence=unknown・Stage B実質無補正・当日情報未反映」
を理由にBETを見送ったPASS判断は、**結果的に見ても慎重すぎる判断ではなく、
むしろ妥当な自制だったと評価できる。**

ただし、これは1レースのみの結果であり、「PASSすれば損をしない」という一般化は
できない。今回はvalue pickが外れたためPASSが結果的に功を奏した形になったが、
別のレースでvalue pickが的中していれば逆の評価になっていたはずである。

## 7. 今回の検証から得られる結論

1. **能力評価（Base Ability V1・Suitability V1）による「上位群の絞り込み」は、
   少なくとも今回1レースにおいては強く機能した。** オッズ・騎手・市場心理を
   一切使わずに11頭から3頭まで正しく絞り込めたことは、「馬の能力が9割」という
   プロジェクトの基本思想（CLAUDE.md）を支持する結果である。
2. **一方で、絞り込んだ上位群「内部の」精密な順位づけ・期待値算出は、まだ
   信頼水準に達していない。** 上位3頭の内部序列は完全に逆転し、value pickは
   5頭中3頭が外れた。
3. **evaluationConfidence=unknownという申告は、結果的に妥当な警告だった。**
   接戦度合い・value pickの不発を踏まえると、「今は自信を持って断定できる
   状態ではない」というAIの自己申告は、後から見ても正確だったと言える。
4. **これらの結論はすべてn=1（1レースのみ）に基づくものであり、断定的な
   結論としては扱わない。** 継続的な実戦検証の蓄積が必要である。

---

## 8. 次に改善優先度が高い項目（最大3項目）

1. **上位群内部での順位精度向上**。特に「新潟実績によるcourse/gate適性評価」
   （ゾロアストロ・バレエマスター・ジュンブロッサムの3例）が、今回n=3で
   1勝2敗という割れた結果になった。サンプルを増やし、この種のcourse
   evidenceが実際にどの程度予測力を持つのか、バックテストで検証する
   優先度が高い。
2. **Race Pace Predictionの精度**。想定"average"に対し実際は"S"（スロー）
   だった。ラップ・展開データが蓄積された段階で、想定ペース分類ロジック
   （legacy`predictedPace.ts`・CHECKPOINT14C `racePacePrediction.ts`）の
   精度を実データで検証する必要がある。
3. **evaluationConfidence=unknownを解消するための当日情報（official going・
   Track Bias・馬体重）の正式接続**。今回はTrack Bias・Weather・馬体重の
   いずれもDiagnostic表示に留まり、Score・confidenceへ反映する正式経路が
   無かった。CHECKPOINT14D.3で設計したStage B Input Contractに基づき、
   Final Stage Bの正式実装を進める優先度が高い。

## 総括

**今回の新潟記念は、モデルの前進を示す「成功寄り」の検証である。**

根拠：オッズ・人気を一切使わない純粋な能力評価だけで、11頭中「馬券に絡む
3頭」を完全に的中させたことは、単一レースの検証としては特筆すべき成果であり、
「馬の能力が9割」というプロジェクトの根幹思想を裏付ける結果だった。同時に、
PASSという投資判断も結果的に妥当な自制だったと言える。一方で上位3頭の内部
序列や中位集団の精密な順位づけには明確な課題が残っており、「完成」を意味する
結果ではない——**次の改善サイクルに正当な根拠を与える、前向きな第一歩**として
記録する。
