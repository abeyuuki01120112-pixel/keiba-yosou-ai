**結論を先に明記する**: 11頭全馬についてBefore→After Base Ability Shadow計算を

「良かったか悪かったか」単体ではなく「既存5走の中で何点が押し出されるか」

production dataは一切変更していない（Shadow計算のみ）。Base Ability V1・

## 使用した実データ

ChatGPT側から提供された、2026新潟記念の実際の結果ページに基づくデータ
（`finishPosition`・`carriedWeight`（実測、確定馬体重ではなく騎乗斤量）・
`actualRaceTimeSeconds`・`displayTimeGapToWinner`・`final3F`・
`passingPosition`・`bodyWeight`・`bodyWeightChange`・`officialMargin`）を
そのままRacePerformance構築用の実データとして使用した。推測・補完は
行っていない。

**precision limitation（最重要の注記）**: 1〜3着（ゾロアストロ・
ロデオドライブ・ダノンシーマ）は公式表示タイムがすべて1:59.6で、
`displayTimeGapToWinner=0.0`として提供された。しかし実際の着差は
「アタマ・アタマ」という非ゼロの着差であり、**JRA公式データが0.1秒単位の
精度までしか公開していないため、この3頭の内部秒差は原理的に取得不能である。**
今回のraceScore計算では、公式データの精度限界に従い`timeGap=0.0`を
**実際の値としてそのまま使用した**（推測でより精密な値を捏造していない）。
この結果、**この3頭の`timeGapScore`は完全に同一値（90点）**となり、
raceScoreの差は`timeGapScore`以外の項目（`final3FScore`・`weightScore`）
のみに由来する。これは「モデルが3頭を区別できていない」のではなく、
「公式データの精度限界が3頭の区別をtimeGap軸では不可能にしている」という、
データソース側の限界である。

## STEP6: 更新量妥当性監査 ＋ rolling-window replacement effect分解

**最重要監査項目**: 今回のDelta（-0.6〜+1.5）が「rolling-window
replacement effect」（新規追加走の評価と、旧5走のうち押し出された走の
評価の差分）でどう説明できるかを、全11頭で分解した。

| 馬名 | 新潟raceScore（新規追加） | 押し出された走（raceId・raceScore） | Delta |
|---|---|---|---|
| ダノンシーマ | 77.1 | JRA-20250928-HANSHIN-09（兵庫特別、75.3） | +0.3（77.1が75.3を上回った分の5分の1相当） |
| ロデオドライブ | 76.8 | なし（既存4走のみ、window未充足） | 0.0（4走→5走化で希薄化） |
| ゾロアストロ | 77.0 | JRA-20250727-NIIGATA-02（2歳未勝利、73.9） | +0.6 |
| ボーンディスウェイ | 72.5 | JRA-20251109-TOKYO-11（75.6） | **-0.6（新規走が押し出された走を下回った）** |
| ジュンブロッサム | 73.9 | JRA-20251018-TOKYO-11（74.5） | -0.1 |
| バレエマスター | 73.0 | JRA-20260124-KYOTO-11（睦月S、67.0） | **+1.2（新規走が押し出された走を6点上回った）** |
| アーバンシック | 75.1 | JRA-20241222-NAKAYAMA-11（有馬記念、73.3） | +0.4 |
| サヴォーナ | 74.2 | JRA-20240714-HAKODATE-11（70.2） | +0.8 |
| ステレンボッシュ | 66.9 | JRA-20250817-SAPPORO-11（59.2） | **+1.5（新規走66.9でも、押し出された走59.2を大きく上回った）** |
| チェルヴィニア | 73.2 | JRA-20250622-HANSHIN-11（71.0） | +0.4 |
| ドゥレッツァ | 74.2 | JRA-20240310-CHUKYO-11（70.3） | +0.8 |

**これが今回の最も重要な発見である**: **Deltaの符号・大きさは、今回の
新潟記念raceScoreの絶対的な高低ではなく、「押し出された過去走の
raceScoreとの相対差」で決まる。**

- **ステレンボッシュ（11着、最下位）が最大の上昇馬（+1.5）になった理由**:
  彼女の新潟記念raceScore（66.9）自体は11頭中最低の絶対値だが、彼女の
  既存5走中最低点（2025-08-17札幌記念、raceScore=59.2）を上回っていた
  ため、平均を押し上げた。**「11着だったから下がる」という直感的な
  予想とは逆の結果**——絶対着順ではなく、raceScoreの相対比較がすべてを
  決めている。
- **バレエマスター（10着）が2番目に大きい上昇馬（+1.2）になった理由**:
  同様に、彼女の既存5走中最低点（2026-01-24睦月S、13着、raceScore=67.0）が
  押し出され、新潟記念のraceScore（73.0）に置き換わった。
- **ボーンディスウェイ（7着、中位）が唯一の下降馬（-0.6）になった理由**:
  彼女の既存5走はいずれも比較的安定して高く、押し出された1走
  （2025-11-09東京、raceScore=75.6）が今回の新潟記念raceScore（72.5）
  より高かったため。**7着という「中位の着順」が、Base Abilityにとっては
  相対的に「悪い置き換え」になった**——これも直感的な着順評価とは
  一致しない。

**構造的リスクの評価**: 上記の通り、Deltaは常に「新旧1走の差÷5」という
機械的な計算の結果であり、`finishPosition`を直接の入力にした着順合わせ
込みは発生していない。**ただし、Delta自体の絶対値（最大1.5pt）は今回の
1レースに関しては過大とは言えない**（baseAbility自体が60〜80点台の
スケールであることを踏まえれば、1.5ptは約2%相当の変化）。

## STEP8: 下位着順馬の更新安定性

- **バレエマスター（AI4位→10着）**: STEP6の通り、Delta=+1.2という
  **上昇**。「1回負けたことで急落する構造」にはなっていない

  上昇だが、**「4着だけを理由に急上昇」というほど極端ではない**

**結論**: 今回検証した範囲では、下位着順馬が不自然に暴落する構造も、
好走馬が不自然に急騰する構造も確認されなかった。
